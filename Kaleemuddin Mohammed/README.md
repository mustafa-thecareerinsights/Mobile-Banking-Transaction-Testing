# Mobile Banking Transaction Workflow Testing

Prepared by: Kaleemuddin Mohammed

## Objective
Perform functional testing of a simulated mobile banking transaction workflow and identify functional, validation, and transaction-handling issues.

## Included Deliverables
- Test scenario document
- Detailed test cases
- Test execution report
- Defect report
- Issue evidence
- Test summary report
- Test data
- GitHub link file

## Test Environment
Local deterministic simulation only. No live banking system, customer account, or real transaction was used.
